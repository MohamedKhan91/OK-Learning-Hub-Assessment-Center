# MohamedKhan91

Public site: **NOK Learning Hub Assessment Center** — one self-contained `index.html` (a seven-part journey of self-discovery: EQ, career & CV, leadership, teams, a four-instrument psychometric assessment centre, the coaching path, team games — with dossier, certificate and a trainer dashboard that collects every trainee's results).

- Live dashboard link: https://mohamedkhan91.github.io/
- Every trainee sends you a share code from their Dossier; paste all codes into the site's **Trainer** tab for a filterable roster + CSV export. Optional live sync is documented inside the Trainer tab (free Supabase project).

The workflow in `.github/workflows/pages.yml` deploys the repository root to GitHub Pages automatically on every push.
